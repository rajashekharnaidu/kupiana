---------------------------

Never skip any module.

Never leave placeholders.

Generate complete production-ready code.

Every page should be fully functional.

Every CRUD should be complete.

Every table should have searching, sorting, pagination, export, filtering, bulk actions, and validation.

Every form should have both client-side and server-side validation.

Use AJAX wherever it improves UX.

Generate reusable layouts, reusable components, reusable modals, reusable tables, and reusable JavaScript.

Use Bootstrap 5 components consistently.

Ensure the UI is visually appealing, modern, responsive, and comparable to premium commercial eCommerce platforms.

Before starting each phase:
1. Explain the architecture briefly.
2. List all files that will be created or modified.
3. Then generate the complete implementation.

Do not skip ahead. Complete one phase entirely before moving to the next, ensuring the application remains runnable after every phase.
